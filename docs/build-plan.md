| 2026-10-05 | Standard agent API: request `{"prompt": "..."}` → response `{"output": "..."}` (+ `session_id`); graphs use `MessagesState`; overridable via `input_mapper`/`output_mapper` |
| 2026-10-05 | Own FastAPI implementation of the AgentCore contract (not `bedrock-agentcore` SDK) — small, transparent, no extra dependency; revisit if the contract grows (streaming, websockets) |
| 2026-10-05 | LLM gateway = Portkey (spec v0.2, §7.6); open-source `portkeyai/gateway` (:8787) locally and in CI |
| 2026-10-05 | Resilience (SDK-16, spec v0.3): Portkey owns LLM retries/fallbacks; the SDK adds timeouts/retries for AWS and tool calls as each feature is built (steps 3–6), plus honest `/ping` and graceful shutdown |
| 2026-10-05 | Coding standards live in the VS Code plugin + policy bundle (steps 8–10, EXT-*), not in the SDK. Focus now: finish the SDK (steps 4–6) |
| 2026-10-05 | `boto3 ~=1.43.108` added to approved versions. `secrets.get(name, key=..., refresh=...)` / `aget`; names `ssm:/path` go to SSM; standard AWS credential chain + `AWS_ENDPOINT_URL`; 5-min cache; fails closed with `SecretsError` / `SecretNotFoundError`; boto timeouts 2 s connect / 5 s read, 3 attempts |
| 2026-10-05 | Trace viewer = **Jaeger** (`jaegertracing/jaeger:2.21.0`, UI :16686, OTLP/HTTP :4318), chosen over Fiddler. Fiddler AI is commercial with no open-source backend; it stays a possible enterprise backend (spec open question 2), reachable by config only |
| 2026-10-05 | Own tracing via a LangChain callback handler (`GraphTracer`), not a third-party instrumentation library: no extra dependency, full control of attributes. Spans: `invoke_agent <agent>` (server) → node/chain → `chat <model>` / `execute_tool <name>`; GenAI semconv + `ent.*` + `fiddler.span.type`. No prompt/response content, no error messages in spans. LangGraph internal runs (`langsmith:hidden`) and the top-level graph run get no span |
| 2026-10-05 | Exporter only via standard `OTEL_EXPORTER_OTLP_ENDPOINT` / `_HEADERS` / `OTEL_RESOURCE_ATTRIBUTES` / `OTEL_SDK_DISABLED`; unset = no export. OTLP over HTTP/protobuf only. W3C `traceparent` from callers is continued; responses return `x-ent-trace-id` |
| 2026-10-05 | FastAPI 0.142's built-in OpenTelemetry is turned off (`telemetry=` all False): it created a second trace, exported metrics Jaeger rejects (404), and records exception messages |
| 2026-10-05 | JSON logs to stdout with `trace_id`/`span_id` (set up by `app.run()`, level from `LOG_LEVEL`). `/ping` returns 503 `Unhealthy` if the optional `health_check` fails; shutdown waits up to `shutdown_timeout` (30 s) for in-flight requests, then flushes spans. New `team=` parameter on `EnterpriseAgentApp` |
| 2026-10-05 | Real-mode providers: **Anthropic + OpenAI**. Registry: `chat-default` → `claude-opus-5-5` with OpenAI fallback (exact OpenAI model ID to confirm from their model list), `chat-fast` → `claude-haiku-4-5` |
| 2026-10-05 | User chose to continue with placeholder keys (`test`) in Floci `llm/anthropic` + `llm/openai`; real keys later. OpenAI fallback set to `gpt-5.6-sol` from a third-party model list (trevorfox.com), **not verified against the user's account**: re-confirm with a real key |
| 2026-10-05 | Open-source Portkey is stateless (no stored keys/configs), so a **model router** (`harness/model-router`, :8788) holds the registry (`registry.json`) and reads provider keys from Secrets Manager (`llm/anthropic`, `llm/openai`); it sends Portkey an inline `x-portkey-config`. Agents send only a logical model name (GW-02/03). With Portkey enterprise (control plane stores configs + virtual keys, data plane caches them) the router is removed; agent code unchanged |
| 2026-10-06 | Real keys tested live.
